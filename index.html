How Answer Index Works

A unified three-phase pipeline bridging real-time LLM perception, diagnostic auditing, and protocol deployment.

Phase 01

Multi-Model Citation Benchmark

Query foundation models simultaneously (Nvidia Nemotron, Google Gemma, Liquid LFM, StepFun) to evaluate how AI models currently perceive your brand and detect citation accuracy.

Phase 02

AEO Engine & Clarity Audit

Conduct deep diagnostic scoring across domain transparency, robot crawler hygiene, verified brand claims, and machine readability standards against Answer Engine guidelines.

Phase 03

Deploy 26-File Manifest Suite

Generate and deploy 18 public web-root protocols (llms.txt, ai.txt, RAG index, schema graphs) and retain 8 internal strategic scorecards and passage-level GEO briefs for your team.

$ npm run ready yourdomain.com

Full Architecture Overview

The Complete 26-File Output

AnswerIndex cleanly separates public machine-readable crawler protocols from internal engineering strategy.

Public Web-Root Protocols 18 Files

Deployed directly to your public web server root for AI crawler extraction:

  • robots.txt AI crawler access governance
  • ai.txt AI transparency & manifest links
  • llms.txt LLM-optimized summary (llmstxt.org)
  • llms-full.txt Full un-truncated context corpus
  • sitemap-main.xml Clean canonical web sitemap
  • ai-sitemap.xml Priority XML map for AI bots
  • ai-entities.json Entity graph & verified brand claims
  • ai-intent.json Query intent to destination routing
  • ai-schema.json Consolidated Schema.org JSON-LD
  • rag-index.json / .jsonl Vector retrieval & embedding chunks
  • .well-known/ai-plugin.json Standard AI plugin descriptor

Internal Diagnostic & Strategy 8 Artifacts

Retained internally for marketing, developer, and SEO strategy:

  • aeo-audit-scorecard.json Machine readability & clarity score
  • ai-citation-benchmark.json Foundation model evaluation tracking
  • geo-content-brief.md 40-60 word passage citability rules
  • cluster-map.html Interactive topic cluster diagram
  • technical-seo-audit.json Crawl, canonical & header audit
  • jsonld-schema-templates.json Ready-to-embed Schema markup
  • schema-validation-report.md Rich result compliance check
  • ai-answer-passages.md Zero-click Q&A snippets for AI

Model Context Protocol

Native AI Assistant Integration

AnswerIndex comes with an integrated MCP server. Inspect AI crawler specifications or trigger full file suite generation directly inside Cursor, Claude Code, Windsurf, or VS Code.

Configure MCP Server →
// Add to .cursor/mcp.json or .mcp.json
{
  "mcpServers": {
    "answerindex": {
      "command": "node",
      "args": ["./lib/mcp-server.mjs"]
    }
  }
}
