Full Architecture Overview

The Complete 26-File Output

AnswerIndex cleanly separates public machine-readable crawler protocols from internal engineering strategy.

Public Web-Root Protocols 18 Files

Deployed directly to your public web server root for AI crawler extraction:

  • robots.txt AI crawler access governance
  • ai.txt AI transparency & manifest links
  • llms.txt LLM-optimized summary (llmstxt.org)
  • llms-full.txt Full un-truncated context corpus
  • sitemap-main.xml Clean canonical web sitemap
  • ai-sitemap.xml Priority XML map for AI bots
  • ai-entities.json Entity graph & verified brand claims
  • ai-intent.json Query intent to destination routing
  • ai-schema.json Consolidated Schema.org JSON-LD
  • rag-index.json / .jsonl Vector retrieval & embedding chunks
  • .well-known/ai-plugin.json Standard AI plugin descriptor

Model Context Protocol

Native AI Assistant Integration

AnswerIndex comes with an integrated MCP server. Inspect AI crawler specifications or trigger full file suite generation directly inside Cursor, Claude Code, Windsurf, or VS Code.

Configure MCP Server →
// Add to .cursor/mcp.json or .mcp.json
{
  "mcpServers": {
    "answerindex": {
      "command": "node",
      "args": ["./lib/mcp-server.mjs"]
    }
  }
}
Instant Deployment

Get Started in 60 Seconds

Open-source software licensed under MIT. Clone and run locally or connect to your deployment pipelines.

bash
# 1. Clone repository & install dependencies
$ git clone https://github.com/justmailsameer-prog/answerindex.git
$ cd answerindex && npm install

# 2. Generate the full 26-file suite for your domain
$ npm run ready yourbrand.com "Your Brand Name"

# 3. Run multi-model foundation citation benchmark
$ npm run benchmark
